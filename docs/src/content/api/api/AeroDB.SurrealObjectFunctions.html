Class SurrealObjectFunctions

SurrealDB object functions for use in LINQ expressions. These methods are NOT callable at runtime — they exist for expression-tree translation only.
Note: object::merge, object::omit, object::pick, object::set are not available in the current SurrealDB version. Add these when a newer version confirms availability.
