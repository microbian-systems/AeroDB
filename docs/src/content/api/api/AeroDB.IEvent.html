Interface IEvent

Non-generic event envelope. Event<T> implements both IEvent<T> and IEvent for maximum compatibility.

Namespace: AeroDB
Assembly: AeroDB.dll
Syntax
public interface IEvent
Remarks

This is deliberately not IEvent<object> because C# does not allow implicit conversion from Event<T> (which implements IEvent<T>) to a separate interface that inherits from IEvent<object>. Instead, Event<T> explicitly implements both interfaces.
