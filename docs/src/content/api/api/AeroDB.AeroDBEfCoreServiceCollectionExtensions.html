AddAeroDBWithEfCore<TDbContext>(IServiceCollection, Action<StoreOptions>)

Registers AeroDB alongside EF Core for coordinated transactions. Consumers must also call UseAeroDBTransactionManager<TDbContext>(DbContextOptionsBuilder) in their DbContext's OnConfiguring method to wire up the transaction manager inside EF Core's internal service provider.

UseAeroDBTransactionManager<TDbContext>(DbContextOptionsBuilder)

Replaces EF Core's default IDbContextTransactionManager with a AeroDB-aware one so that Database.BeginTransaction() coordinates both SurrealDB and EF Core changes. Call this inside your DbContext's OnConfiguring method:

protected override void OnConfiguring(DbContextOptionsBuilder options)
    => options.UseAeroDBTransactionManager<MyDbContext>();
