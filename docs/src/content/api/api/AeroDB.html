CompiledQueryPlanner

Static planner for interface-based compiled queries (Marten-compatible pattern).

For each unique compiled query type, the planner builds a CompiledPlan once and caches it. The plan stores:

  • The SurrealQueryResult skeleton with sentinel parameter values.
  • A mapping from SurrealQL parameter keys ($p0, $p1, …) to query property names.
  • Which properties (if any) supply the LIMIT / START values.

At execution time the skeleton is cloned, property values are read from the query instance, parameters are substituted, and the query is executed.

EnumStorage

EventAppendMode

Controls how events are appended to the event store.

EventSerializationMode

Controls how event data is serialized in the event store.

IndexType

The type of SurrealDB index to create.

OperationType

Describes the type of change tracked in a document session's unit of work (Added, Modified, Deleted, SoftDeleted, Insert, Update).

ProjectionLifecycle

Defines when a projection is applied. Inline projections run synchronously during SaveChanges; Async projections are processed by the background daemon; Live projections are computed on-demand at read time.

ReadPreference

Controls which endpoint is used for read operations.

SchemaMode

Controls the SurrealDB table schema mode. Schemaless (Flexible) allows any fields; Schemafull (Strict) enforces a strict field definition.

SnapshotLifecycle

When a snapshot projection should be rebuilt/refreshed. Maps to Marten's SnapshotLifecycle.

SortOrder

No-op stub for Marten portability. SurrealDB does not use index sort orders.

StaleDataMode

Controls staleness tolerance for QueryForNonStaleData<T>.

StreamIdentity

Stream identity strategy for event store streams.

TenancyScope

No-op stub for Marten portability. SurrealDB does not use tenancy-scoped indexes.

TenancyStyle

Defines the multi-tenancy strategy. Single for single-tenant; Conjoined uses a tenant_id field within a single database; DatabasePerTenant routes each tenant to a separate database.

TenantIdStyle

Controls whether tenant IDs are treated as case-sensitive or case-insensitive when matching multi-tenanted documents.

TimeBucket

Predefined time buckets for calendar-aligned grouping via time::group().

TimeUnit

Time units for duration-based bucketing via time::floor().

Delegates

ProjectionRebuildProgressCallback

Reports progress during projection rebuilds.
