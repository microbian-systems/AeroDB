Interface ITenantOperations

Cross-tenant document operations within a session. Provides access to per-tenant query sessions for multi-tenancy scenarios.

Namespace: AeroDB
Assembly: AeroDB.dll
Syntax
public interface ITenantOperations
Remarks

Marten parity: ITenantOperations / ITenantQueryOperations provide ForTenant(tenantId) => IQuerySession to scope operations to a specific tenant.
Existing AeroDB API: AeroDB already achieves the same capabilities through:

  • WithTenant(string) — sets tenant for the next session creation.
  • SetTenant(string) — scopes a session to a tenant.
  • ForTenant(string) — returns a session scoped to a tenant.

This interface provides a unified Marten-compatible surface over those APIs.
