Class SurrealTypeFunctions

SurrealDB type conversion and type-check functions for use in LINQ expressions. These methods are NOT callable at runtime — they exist for expression-tree translation only.

IsNone(object)

Checks if a value is NONE (missing/absent). Equivalent to x.Field == null in LINQ expressions. SurrealDB distinguishes NONE (absent) from NULL (JSON null). See IsNull(object) for NULL checking. Maps to type::is_none(value).

IsNull(object)

Checks if a value is NULL (JSON null). This is NOT equivalent to x.Field == null in LINQ, which checks for NONE (absent). Use this for explicit SurrealDB NULL checking. Maps to type::is_null(value).
