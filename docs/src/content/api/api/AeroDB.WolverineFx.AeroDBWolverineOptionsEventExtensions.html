ForwardAeroDBEventsToWolverine(WolverineOptions, Action<StoreOptions>?)

Configure Wolverine to forward events appended to AeroDB event streams as Wolverine messages. Events are published atomically within the same transaction as the document session's save operation.

Event forwarding is automatically enabled when sessions are created through AeroDBOutboxedSessionFactory. This method provides additional configuration hook for the AeroDB StoreOptions.
