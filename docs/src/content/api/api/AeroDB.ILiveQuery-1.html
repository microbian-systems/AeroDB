Interface ILiveQuery<T>

Marten API parity: legacy live query interface. Wraps IAeroDBLiveQuery<T> for backward compatibility with Marten's IQuerySession.WatchTableAsync, WatchQueryAsync, and WatchStreamAsync methods. Prefer ILiveQuerySession for new code.
