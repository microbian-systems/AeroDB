Interface ISpatialQuery<T>

Fluent builder for SurrealDB spatial (geo) queries. Supports Nearby, Within, OrderByDistance, filtering, sorting, and pagination. Obtained via session.Spatial<T>().

NearBy(Expression<Func<T, object>>, double, double, double)

Finds documents located within a specified distance from a reference point. Generates a bounding-box pre-filter + geo::DISTANCE post-filter. Results are sorted by distance ascending.
