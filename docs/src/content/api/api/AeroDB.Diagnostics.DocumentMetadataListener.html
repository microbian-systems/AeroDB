Class DocumentMetadataListener

Document session listener that auto-populates IDocumentMetadata properties (CreatedAt, LastModified, LastModifiedBy) during store operations.

Register via StoreOptions.Listeners.Add(new DocumentMetadataListener()) or use the convenience extension method o.EnableDocumentMetadata().
