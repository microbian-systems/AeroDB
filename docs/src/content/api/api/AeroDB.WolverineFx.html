Namespace AeroDB.WolverineFx

Classes

AeroDBEndpoint

AeroDB endpoint backed by SurrealDB message storage. Creates AeroDBQueueListener and AeroDBQueueSender for message processing.

AeroDBEnvelope

SurrealDB record type for Wolverine message envelopes. Maps to wolverine_incoming_envelopes and wolverine_outgoing_envelopes tables. The body is stored as Base64 string (SurrealDB CBOR byte[] round-trip may be unreliable).

AeroDBIntegration

Wolverine extension that integrates AeroDB (SurrealDB) as the message persistence and saga storage provider. Registers codegen sources, persistence frame provider, and the AeroDB transport.

AeroDBMessageStore

SurrealDB (AeroDB) backed implementation of Wolverine's IMessageStore and all sub-interfaces. All operations use SurrealQL RawQuery with parameterized queries. Envelope bodies are stored as Base64 strings for reliable CBOR round-tripping.

Schema initialization now delegates to the AeroDB SchemaManager pipeline via typed POCOs (AeroDB.WolverineFx.WolverineIncomingEnvelope, etc.) instead of a hardcoded SurrealQL string.

AeroDBOps

AeroDBOutboxedSessionFactory

Factory that creates IDocumentSession instances pre-enrolled in Wolverine's outbox. Mirrors the Wolverine.Marten OutboxedSessionFactory pattern.

AeroDBQueueListener

Polling listener that claims and dispatches incoming messages from SurrealDB. Uses the AeroDBMessageStore to load globally-owned incoming envelopes, then dispatches them to the provided IReceiver.

AeroDBQueueSender

Sends outgoing messages by inserting them into the SurrealDB wolverine_outgoing_envelopes table via AeroDBMessageStore.

AeroDBSagaStorage<TId, TSaga>

AeroDB-backed saga storage for Wolverine using SurrealDB as the document store.

AeroDBTransport

AeroDB-backed transport for Wolverine using SurrealDB as the message store. Registers the "AeroDB://" protocol scheme and creates AeroDBEndpoint instances.

AeroDBTransportOptions

Configuration options for the AeroDB-backed transport. Controls polling behavior and batch sizes for the SurrealDB message queue.

AeroDBWolverineOptionsEventExtensions

Extension methods for configuring AeroDB event forwarding through Wolverine. Event forwarding is automatically wired when sessions are opened via AeroDBOutboxedSessionFactory. This method provides additional store-level configuration for event-related options.

ScopedDocumentSessionHolder

Scope-local carrier for the outbox-enrolled IDocumentSession a handler is using. When a handler falls back to service location, Wolverine's generated code primes this holder so a service-located IDocumentSession / IQuerySession resolves to the SAME session enrolled with the active outbox. See GH-3001.

WolverineEnvelopeSchemas

Registers Wolverine envelope table schemas on Schema during InitializeAsync(CancellationToken) via the IConfigureAeroDB hook. This replaces the hardcoded 131-line SchemaScript string in AeroDBMessageStore with proper typed POCOs and the AeroDB schema pipeline.

WolverineOptionsAeroDBExtensions

Extension methods for integrating Wolverine with AeroDB (SurrealDB) persistence.

WolverineOptionsSubscriptionExtensions

Extension methods for registering AeroDB event subscriptions with Wolverine.

Interfaces

IAeroDBOp

Side effect that executes against a AeroDB document session.
