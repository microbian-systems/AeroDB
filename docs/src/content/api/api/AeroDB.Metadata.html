Namespace AeroDB.Metadata

Classes

MetadataRegistry

Central registry for per-type metadata generated by the AeroDB source generator. Generated {Type}Metadata classes self-register in their static constructors. Runtime code queries the registry to avoid reflection in hot paths.

Structs

FieldSchema

Compile-time schema for a document property, emitted by the AeroDB source generator. Used by SchemaManager to emit DEFINE FIELD statements without reflection.

Interfaces

IDocumentMetadata

Marks a document as having auto-tracked audit metadata. Properties are populated automatically by DocumentMetadataListener during SaveChangesAsync(CancellationToken).

ITypeMetadata

Generic metadata interface for a document type.

ITypeMetadata<T>

Typed metadata interface for a specific document type T. Generated metadata classes implement this interface.
