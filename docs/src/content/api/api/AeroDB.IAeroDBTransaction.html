Interface IAeroDBTransaction

Represents an explicit SurrealDB transaction started by BeginTransactionAsync(CancellationToken) or BeginTransaction(). Supports multiple SaveChangesAsync(CancellationToken) calls within a single transaction. Implements IAsyncDisposable — rolling back if not committed before disposal.
