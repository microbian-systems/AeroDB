ToObservable<T>(IAeroDBLiveQueryBuilder<T>, CancellationToken)

Bridges the live query builder to an IObservable<T> of AeroDBLiveChange<T>. Each subscriber triggers a fresh SubscribeAsync(CancellationToken) call (deferred execution). The server-side query starts only when the first subscriber attaches. Unsubscribing disposes the underlying query.
