Interface IDocumentOperations

Document CRUD operations shared between IDocumentSession and projection operations. Provides the raw document read/write surface without session lifecycle methods.
Note: LoadAsync<T>(id) is available via IQuerySession cast — intentionally omitted to avoid diamond ambiguity with IQuerySession in the IDocumentSession hierarchy.
