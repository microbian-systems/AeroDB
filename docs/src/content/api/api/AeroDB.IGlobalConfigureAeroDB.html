Interface IGlobalConfigureAeroDB

Marker interface for IConfigureAeroDB implementations that apply globally to all store types (primary and secondary). Mimics Marten's IGlobalConfigureMarten.

Inherited Members
IConfigureAeroDB.Configure(StoreOptions)

Namespace: AeroDB
Assembly: AeroDB.dll
Syntax
public interface IGlobalConfigureAeroDB : IConfigureAeroDB
Remarks

Configurators implementing only IConfigureAeroDB are applied to the primary store only. Implement IGlobalConfigureAeroDB (in addition to IConfigureAeroDB) to have the configurator applied to secondary stores as well.
