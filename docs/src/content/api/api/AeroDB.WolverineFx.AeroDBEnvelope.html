Class AeroDBEnvelope

SurrealDB record type for Wolverine message envelopes. Maps to wolverine_incoming_envelopes and wolverine_outgoing_envelopes tables. The body is stored as Base64 string (SurrealDB CBOR byte[] round-trip may be unreliable).
