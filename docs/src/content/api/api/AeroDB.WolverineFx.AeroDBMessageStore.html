Class AeroDBMessageStore

SurrealDB (AeroDB) backed implementation of Wolverine's IMessageStore and all sub-interfaces. All operations use SurrealQL RawQuery with parameterized queries. Envelope bodies are stored as Base64 strings for reliable CBOR round-tripping.

Schema initialization now delegates to the AeroDB SchemaManager pipeline via typed POCOs (AeroDB.WolverineFx.WolverineIncomingEnvelope, etc.) instead of a hardcoded SurrealQL string.

Registry of dynamic, runtime-registered listener URIs. Opt-in via Wolverine.DurabilitySettings.EnableDynamicListeners; providers must return Wolverine.Persistence.Durability.NullListenerStore.Instance (and skip schema migrations for the listener table) when the flag is false.
