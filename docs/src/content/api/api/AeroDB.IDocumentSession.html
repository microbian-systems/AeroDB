Interface IDocumentSession

A read/write session that extends IDocumentOperations and IQuerySession with document storage (Store/Delete/BulkInsert), event sourcing (Append/StartStream), and unit-of-work change tracking.

BeginTransaction()

Begins an explicit SurrealDB transaction. Returns an IAeroDBTransaction for explicit commit/rollback control. When active, SaveChangesAsync(CancellationToken) runs inside this transaction without auto-committing, supporting multiple SaveChangesAsync calls within a single transaction.

Alternative: use CommitTransactionAsync(CancellationToken) or RollbackTransactionAsync(CancellationToken) on the session directly.
