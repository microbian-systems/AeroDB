Class SurrealFunctions

SurrealQL search and vector functions for use in LINQ expressions. These methods are NOT callable at runtime — they exist for expression-tree translation only. Use MatchTextAsync<T> and MatchKnnAsync<T>(ISurrealDbQueryable<T>, Expression<Func<T, float[]>>, float[], int, int, CancellationToken) for query execution.
