Class DocumentSession

BeginTransactionAsync(CancellationToken)

Begins an explicit SurrealDB transaction asynchronously. Returns an IAeroDBTransaction for explicit commit/rollback control. When active, SaveChangesAsync(CancellationToken) runs inside this transaction without auto-committing, supporting multiple SaveChangesAsync calls within a single transaction.

Alternative: use CommitTransactionAsync(CancellationToken) or RollbackTransactionAsync(CancellationToken) on the session directly.
