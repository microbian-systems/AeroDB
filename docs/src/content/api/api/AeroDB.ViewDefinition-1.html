Class ViewDefinition<T>

Fluent builder for SurrealDB pre-computed/aggregate views (DEFINE TABLE ... AS SELECT ...). Views are materialized, incrementally-updating tables backed by a SELECT query.

Where(Expression<Func<T, bool>>)
