SurrealQueryProvider(ISurrealDbSession, InternalSessionBase?, StoreOptions, string?)

Creates a query provider with optional InternalSessionBase for schema-based session routing. When sessionBase is provided, queries are routed through the correct forked session based on the element type's schema mapping.
