DiskannIndex<TProp>(Expression<Func<T, TProp>>, int, string, string, int?, int?, double?, bool)

Defines a DISKANN vector index on the specified property. DiskANN is a disk-based approximate nearest-neighbour index for very large embedding sets. Uses the same <|K, EF|> query operator as HNSW. Available since SurrealDB 3.1. Best when the working set exceeds available RAM.

Declaration
public DocumentMapping<T> DiskannIndex<TProp>(Expression<Func<T, TProp>> property, int dimension, string vectorType = "F32", string distance = "COSINE", int? degree = null, int? lBuild = null, double? alpha = null, bool hashedVector = false)
Parameters
Type Name Description
Expression<Func<T, TProp>> property

The property storing the vector embedding.
int dimension

The dimensionality of the vector.
string vectorType

Element type: F32 (default), F16, I8, or U8.
string distance

The distance function: COSINE (default), EUCLIDEAN, INNER_PRODUCT, or COSINE_NORMALIZED.
int? degree

DiskANN graph degree (default 64). Higher values improve accuracy at cost of memory.
int? lBuild

Construction search-list size (default 100).
double? alpha

DiskANN pruning parameter (default 1.2).
bool hashedVector

Whether to use hash-stabilized vector keys.
