Interface IConfigureAeroDB<TStore>

Typed variant of IConfigureAeroDB for store-specific configuration. Mimics Marten's IConfigureMarten<T>. When multiple store types exist, implementations of this interface are applied only to the matching store type (secondary store pattern).
