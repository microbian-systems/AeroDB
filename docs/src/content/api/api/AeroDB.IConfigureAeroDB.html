Interface IConfigureAeroDB

DI-registered (or directly added) AeroDB configuration module. Implementations are applied during InitializeAsync(CancellationToken).

Implementers may override either overload:

  • Configure(StoreOptions) — simple configuration (backward-compatible).
  • Configure(IServiceProvider?, StoreOptions) — configuration with DI service access.

The two-parameter overload has a default implementation that delegates to the single-parameter overload, so existing implementations need no changes.
