## Why AeroDB?

AeroDB is a high-performance document database for .NET that combines the simplicity of Marten's API with SurrealDB's multi-model engine. It supports documents, graph relationships, event sourcing, live queries, and full-text search — all through a clean, idiomatic .NET interface.

> **Requires SurrealDB 3.1 or later.** AeroDB targets SurrealDB 3.1+ features and is not compatible with SurrealDB 2.x. Install a local instance, connect to a remote server, or use [SurrealDB Cloud](https://surrealdb.com/cloud).
