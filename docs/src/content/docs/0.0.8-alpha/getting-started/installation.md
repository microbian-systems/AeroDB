AeroDB is available as NuGet packages. Add the core package to your project:

```bash
dotnet add package AeroDB
```

For ASP.NET Core Identity support:

```bash
dotnet add package AeroDB.AspNetIdentity
```

For Wolverine integration:

```bash
dotnet add package AeroDB.WolverineFx
```

## Requirements

* .NET 10 or later
* SurrealDB 2.x (local, remote, or cloud)
