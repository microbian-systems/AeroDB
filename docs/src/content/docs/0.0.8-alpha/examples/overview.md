AeroDB exposes SurrealDB's full multi-model engine — documents, graph, time-series, search, and live queries — through a clean, idiomatic .NET API. Each example below highlights one pillar with a code snippet and links to a complete working sample.

| Pillar | Example | Full Sample |
|---|---|---|
| Configuration | Connection setup, session options | [`samples/MinimalAPI/`](https://github.com/microbians/AeroDB/tree/main/samples/MinimalAPI) |
| Querying | Fluent LINQ + raw SurrealQL | [`samples/DocSamples/`](https://github.com/microbians/AeroDB/tree/main/samples/DocSamples) |
| Graph | Graph edges, path traversal | [`samples/WikipediaSearch/`](https://github.com/microbians/AeroDB/tree/main/samples/WikipediaSearch) |
| Time Series | Time-bucketed queries | [`samples/CryptoTrader/`](https://github.com/microbians/AeroDB/tree/main/samples/CryptoTrader) |
| Live Queries | Reactive subscriptions via Rx.NET | [`samples/`](https://github.com/microbians/AeroDB/tree/main/samples) |
| Event Sourcing | Events, projections, async daemon | [`samples/EventSourcingIntro/`](https://github.com/microbians/AeroDB/tree/main/samples/EventSourcingIntro) |
| Full-Text Search | Search indexes and vector search | [`samples/WikipediaSearch/`](https://github.com/microbians/AeroDB/tree/main/samples/WikipediaSearch) |

All samples live in the [AeroDB samples directory](https://github.com/microbians/AeroDB/tree/main/samples).
